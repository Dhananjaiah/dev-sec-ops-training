# Linux Administration Course - Quick Start Guide

## 📋 Course Overview

This is a comprehensive, **command-first** Linux administration course covering beginner to advanced topics. All content is in the `/docs` directory.

## 🚀 Getting Started

1. **Start Here:** Read [docs/README.md](docs/README.md) for full course overview
2. **Begin Learning:** Start with [Module 01: Foundations](docs/modules/module-01-foundations.md)
3. **Use Cheatsheets:** Quick references in [docs/cheatsheets/](docs/cheatsheets/)

## 📚 Course Structure

### Core Modules (1-8)
Foundation, text processing, users, permissions, processes, packaging, storage, LVM/RAID

### Networking (11-12)
Network essentials, advanced networking, firewalls

### Operations (17-18, 25, 29)
SSH, task scheduling, scripting, troubleshooting

### Capstones (30)
Real-world integration projects

## 💡 Practice Environment

You **need** a Linux system. Options:
- **VirtualBox/VMware:** Ubuntu 22.04 LTS (recommended for beginners)
- **Cloud:** AWS EC2 t2.micro (free tier)
- **WSL2:** Limited but good for basics

**⚠️ Take snapshots before destructive labs!**

## 🎓 Learning Path

1. Complete modules 1-8 (foundations)
2. Add module 11 (networking basics)
3. Add modules 17, 25, 29 (SSH, scripting, troubleshooting)
4. Complete at least one capstone (module 30)
